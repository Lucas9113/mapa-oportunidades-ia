## 📖 ¿De qué trata la app?

**Mapa de Oportunidades con IA** es una plataforma colaborativa donde cualquier usuario puede descubrir y registrar oportunidades de negocio basadas en Inteligencia Artificial detectadas en distintas partes del mundo:

* **Publicar oportunidades:** Comparte problemas reales identificados en cualquier ciudad o país junto con su solución basada en IA, categoría y nivel de potencial.
* **Filtros dinámicos:** Explora las oportunidades filtrando por ciudad, país o sector (Salud, Finanzas, Gastronomía, Movilidad, Educación, etc.).
* **Sistema de Likes:** Vota por las mejores propuestas con actualización y recuento en tiempo real.
* **Panel de estadísticas:** Visualiza métricas animadas con el total de oportunidades, ciudades, países alcanzados y apoyo recibido.

## 🛠️ Tecnologías utilizadas

* **Frontend:** HTML5 semántico, Vanilla CSS y JavaScript moderno.
* **Base de datos & Backend:** [Supabase](https://supabase.com/) (PostgreSQL con políticas RLS y funciones RPC).
* **Entorno de desarrollo IA:** [Google Antigravity](https://antigravity.google/) con conexión al servidor MCP oficial de Supabase (`@supabase/mcp-server-supabase`).
* **Despliegue:** GitHub Pages.
